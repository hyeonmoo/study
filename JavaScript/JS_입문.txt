alert()		경고창 출력
confirm()		확인창 출력
prompt()		입력창 출력
console.log()	콘솔창에 내용 출력
document.write()	화면에 내용 출력(html태그 입력 가능)

변수	var 변수이름 = 초기값;
	숫자형, 문자열, 논리형, 배열, 객체, undefined, null값을 저장 가능
	typeof var : 해당 변수의 자료형 출력
	undefined : 정의되지 않았을 때 데이터의 상태, 변수에 값이 할당되지 않았음을 의미
	null : 데이터의 값이 유효하지 않은 상태, 변수에 할당된 값이 유효하지 않음을 의미
	데이터 유형이 자동 변환되는 점은 편리하나, 원하지 않는 자료형으로 변환될수도 있다는 단점도 있음.
	parseInt() : 정수형으로 형변환

Math	random()		0~1사이의 랜덤한 수 리턴
	floor()		내림
	round()		반올림
	ceil()		올림
window	기본객체

	protocol	URL의 프로토콜
	replace	현재 문서의 URL을 다른 URL로 교체
